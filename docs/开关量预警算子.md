# 开关量预警算子原型

## 确认范围

所属工程：TFIIF2026_LY。原型路径：应用创建中心 → 智能模型-新增算子 → 开关量预警算子。公共工作台目前按模块与页面显示两级菜单，第三级以页面内页签呈现，不修改公共工具。

用户确认只制作新增算子区域，其他区域使用用户提供的第三张截图。截图原始尺寸 1907×910，保存在 references/智能模型-时序函数原始截图.png。所有新增热区共享截图设计坐标系，随自适应与 75% / 100% / 125% 缩放。

## 新增交互

- 入口位于基础功能块 → 数学函数 → 时序函数，紧接 SC-PC 后新增一行，左列为「开关量预警」。
- 拖动入口到中央画布添加节点；双击或按 Enter 为快捷添加。初始不预置新节点。可多次添加，默认名称递增。
- 节点为时序函数的青色渐变标题、白色主体、IN / OUT 分区；点击主体或标题打开属性框，拖动标题可移动节点。
- 属性框局部覆盖右侧工具箱，关闭后恢复原截图。输入、预警结果各一路，保留顶部流程判断端口的视觉。
- 输入弹窗支持选择一个模拟开关量测点，或选择截图 Value 节点的模拟上游输出；上游来源赋值后显示曲线连线、来源只读，断开后可重新配置。
- 配置草稿实时反映在选中节点及规则预览；「应用配置」检查名称、来源和当前模式相关字段后应用。取消、关闭或切换节点时，未应用草稿会确认是否放弃。删除只影响新增节点及其展示连线。
- 所有配置仅保留在当前 React 会话中，刷新重置；不写入业务文件或浏览器持久存储。

## 判定配置

| 模式 | 字段 | 初始值 |
|---|---|---|
| 状态命中 | 目标状态 | 1 |
| 状态跳变 | 跳变方向、保持时间 | 任意跳变、1 秒 |
| 连续状态超时 | 目标状态、持续时间 | 1、60 秒 |
| 短时脉冲 | 目标状态、严格小于的时长阈值、保持时间 | 1、2 秒、1 秒 |
| 窗口跳变次数 | 方向、统计窗口、比较符、次数 | 任意、60 秒、≥5 次 |
| 窗口累计时长 | 目标状态、统计窗口、比较符、累计秒数 | 1、300 秒、≥120 秒 |
| 窗口状态占比 | 目标状态、统计窗口、比较符、百分比 | 1、300 秒、≥80% |

默认模式为连续状态超时。切换模式重置相关阈值和比较符，保留名称、输入来源、目标状态、方向和高级配置。隐藏字段不参与当前模式校验。

时间为正整数，单位秒 / 分 / 时 / 日，换算后 1 秒～30 天。次数为整数，≥ 时最小 1，≤ 时允许 0，上限 1000000。累计秒数为非负整数且不得超过窗口。占比为 0～100%，最多两位小数。名称 1～50 字符，去首尾及重复空白，当前画布内唯一。

高级配置包含最大无更新时长，默认 5 秒；说明数据中断后结果无效，不能直接当作 0 恢复。字段标签通过 @workbench FieldLabel 复用问号说明。
